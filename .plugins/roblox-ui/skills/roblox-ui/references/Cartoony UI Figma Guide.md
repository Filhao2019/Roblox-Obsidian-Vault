# Cartoony UI Figma Guide

Agent-ready brief for building polished, cartoony Roblox menus in Figma and Studio: layered strokes (≈ radius 10, black 3, white 6, inner 4 at 1080p), offset dark underlays, gradient rarity cards, masked halftones, outlined titles and a staged production workflow. Pair it with [[Stud UI Figma Guide]] for HUD buttons and [[Figma Workflow for Roblox UI]] for the Figma-to-Studio handoff.

## 1. Establish the Visual Identity and Design Foundations

Create a distinctive, highly polished **cartoony Roblox UI**, not a flat website dashboard or a generic modern app. The defining appearance is colorful, playful, soft-edged, dimensional, and immediately readable: large rounded rectangles, bold high-contrast borders, bright saturated colors, controlled gradients, stacked layers, strong visual hierarchy, and small decorative details that make each menu feel like part of a cohesive game world. Begin by defining the entire design system before placing individual controls. In Figma, start with a **1920 × 1080** design frame, as shown around **00:44–01:06**, and treat it as a reference canvas rather than a guarantee that fixed pixel sizes will work on every Roblox device. Choose a compact palette containing a main interface/background color, one or two accent hues, distinct semantic colors for rarity or action states, a dark near-black outline, white or near-white highlight borders, and shaded darker versions of each surface color. Build the interface around a large central inventory or shop window, with appropriately scaled subpanels, buttons, search inputs, item tiles, labels, and a clearly recognizable close control. Position the main window symmetrically, with comfortable interior padding and clean margins; allow each element to breathe rather than cramming in effects. Consistency is more important than sheer saturation: reuse the same corner-radius families, border thickness hierarchy, highlight direction, shadow direction, and color relationships across every panel. The final style should resemble expertly authored playful game art, with each asset feeling intentionally illustrated rather than randomly generated. **Agent instruction:** before making the screen, define reusable design tokens for colors, radii, outline widths, spacing, typography, depth, and animation behavior. Generate a representative panel, item card, and button as a mini style guide; use those as references for the entire interface. Avoid photorealism, excessive glassmorphism, thin corporate borders, unrelated icon packs, and generic grey placeholder aesthetics.

## 2. Construct Signature Rounded Frames, Layered Borders, and Depth

The video's most identifiable technique is **assembling visual depth out of rounded shapes, duplicated layers, multiple outlines, and carefully placed shadows**. Around **01:44–05:27**, the designer draws the base window, adjusts its radius, adds borders, duplicates shapes to simulate multiple border layers, chooses inside/outside stroke placement, groups the finished elements, and names layers for easier editing. A separate technical source records the tutorial's approximate **1080p reference recipe: corner radius 10, black outer stroke 3, white outer stroke 6, and inner stroke 4**, discussed around **12:11 and 24:27**. Treat these as reference-scale design values, not rigid universal pixel constants; resize proportionally when necessary to preserve the intended visual weight. Construct a strong silhouette using a near-black outside stroke; surround or nest a clean white/light highlight stroke; and add another colored inner outline to separate the frame from the interior fill. Rounded borders must stay smooth and visually even around the corners. The border ordering and exact placement matter: a white layer can read as a shiny protective edge while a thin dark layer anchors the panel against a colorful background. Add depth by duplicating a component, placing the copy slightly **downward** and occasionally rightward, and changing the copy to a darker shade of the foreground color; this creates a chunky raised-cartoon effect rather than a vague floating shadow. The tutorial also demonstrates flattening overlapping components into a single vector before applying a unified stroke, notably around **10:24** and **30:18**, so borders do not fracture or double up where shapes touch. Use restrained soft drop shadows to separate large windows from the scene, while keeping the crisp offset dark-shape shadows that define the cartoony style. Apply the same visual construction logic to panel shells, button bodies, tabs, search bars, item cards, and headers. **Agent instruction:** implement this as reusable layered component recipes, not hand-tuned one-offs; ensure the Roblox `UICorner`, `UIStroke`, nested `Frame`, `UIGradient`, and supporting shadow layers reproduce the intended appearance where practical. For advanced artistic borders that Roblox primitives cannot closely match, export only the required ornamental layers or nine-slice images rather than flattening all text and interaction elements into a single picture. Preserve editable, native controls and avoid blurry or uneven borders.

## 3. Add Rich Item Cards, Controlled Gradients, Textures, Icons, and Highlight Effects

The middle of the tutorial focuses on building attractive item or pet frames, beginning around **08:47** and continuing through **18:46**, then refining their colors and textures later around **34:58–40:02**. Each item card should read as a small, premium cartoon object with its own color identity, while remaining visibly part of the same interface system. Use a color gradient rather than an undifferentiated solid fill: for a gold or legendary card, transition between warm yellow, amber, and orange; for an epic rarity card, shift between vivid violet and a deeper purple. Keep gradients intentional and simple, with a consistent simulated lighting direction. Make the main card surface brighter than the offset backing layer, then use a thin highlight to communicate curvature and polish. Use **clipped or masked decorations** to enrich the background without obscuring the item: the tutorial applies masking techniques around **12:28** and **37:06**, blending modes such as **Overlay** and **Soft Light** around **14:21**, and dotted **halftone textures** beginning around **15:11**, then adds more halftone decoration in the later header refinements. Halftone dots should be used as a subtle game-art accent, not wallpaper everywhere: place them in corners, along side regions, or behind key items and reduce their contrast so they support rather than compete with important content. Apply highlights, small specular shapes, subtle edge lighting, and occasional sparkles sparingly to create a toy-like, premium finish. Use visually consistent cartoon icon assets, preferably rounded and with the same outline/shading treatment as the rest of the UI, rather than mixing unrelated emoji, ultra-thin symbols, and high-detail illustrations. When building a collection of cards, duplicate a validated master card and alter only the item icon, label, rarity color, badge, or status; maintain identical geometry, stroke layering, spacing, and shadow offsets. **Agent instruction:** define each card's configurable data fields (`name`, `icon`, `rarity`, `selected`, `equipped`, `locked`) and derive visual states from the design tokens. Ensure selection is perceivable through more than color alone: add a border, checkmark, title, or other symbol. Make sure background patterns do not reduce contrast or overwhelm the inventory item image. The target is high-detail polish without visual clutter.

## 4. Design Hierarchy, Headers, Search Fields, Buttons, and Balanced Layout

The tutorial assembles a working visual composition from recognizable parts rather than decorating isolated rectangles: **main frame (00:37), search bar (05:30), pet/item frames (08:47), main buttons (19:32), close button (29:03), and header (31:27)**. Reconstruct this hierarchy deliberately. Give the main menu a bold top header containing a readable title such as **Inventory**, framed as a colorful strip or inset shape and supported by a strong outline and subtle dimensional offset. Use large, rounded, weighty typography that matches the cartoon aesthetic, with white or bright text against darker/saturated panels and a dark stroke or shadow for legibility; around **32:51** the video adds title text with stroke effects. Position the search bar near the top of the content area as a readable, recessed field: a slightly darker inner surface, an inner shadow or inset illusion, a search icon, and enough text padding to make typing feel comfortable. The video specifically constructs and aligns the search field around **05:27–06:48**, emphasizing careful centering of its text. Build repeated pet/item slots in an orderly grid with regular gaps; duplicate objects efficiently while maintaining consistent vertical and horizontal alignment, as demonstrated around **17:51–18:46**, and correct layout drift by aligning multiple frames together, as seen around **40:02**. Main action buttons should be chunky and prominent, with gradients and the same radius/outlining vocabulary as the window; the video starts constructing them around **19:11–20:05** and continues refining them. Make the close button easy to identify, with a contrasting shape and a clear X, and place it near the panel's upper-right corner without visually colliding with the header. Keep typography, margins, card width, button height, and icons on a consistent spacing system. **Agent instruction:** design first for clear information architecture and navigation, then apply visual treatments. Use responsive Roblox layout tools such as `UIGridLayout`, `UIListLayout`, `UIPadding`, `UISizeConstraint`, `UIAspectRatioConstraint`, and thoughtful combinations of `Scale` and `Offset`; avoid assuming that Figma's 1920 × 1080 reference layout directly translates to every phone, tablet, or desktop display. Keep the UI inside safe screen insets, support scrolling where the card count grows, and test the composition at several screen sizes. Maintain a strong primary action, readable labels, and enough contrast for accessibility.

## 5. Turn the Tutorial Into an Agent-Ready Production Workflow With Quality Standards

Act as a **senior Roblox UI designer, Figma component artist, and Roblox Studio Luau implementer**. The mission is not to blindly trace the video's final screen but to **reproduce its visual design principles in an original, functional cartoony interface** suitable for any Roblox game. Follow a staged process. First inspect the target game's theme, player age range, menu purpose, and required controls, then create a short design specification and a reusable token sheet. Second construct the primary visual panel in Figma or native Roblox UI with consistent rounded edges, black/white/colored layered strokes, shaded underlays, and soft drop shadows. Third make reusable cards, search fields, top buttons, close buttons, and header variants with gradients, clipped halftones, decorative textures, bold outlined titles, and consistent iconography. Fourth assemble the page into a balanced responsive hierarchy, implement actual Roblox behavior, and add subtle interaction animations: buttons can depress a few pixels on press, shrink or spring gently on click, lighten on hover, and return smoothly to a default state; panels can open with a quick scale-and-fade animation, and item cards can show a restrained selected or equipped state. These animation and engineering recommendations go **beyond the demonstrated Figma illustration tutorial** and should be implemented only where they improve interaction clarity. Fifth test and iterate: inspect at desktop, mobile, and tablet sizes; verify padding, alignment, corner joins, text overflow, active states, scrolling, camera-safe zones, contrast, motion preferences, and button responsiveness. Ensure all objects and code remain organized in clearly named groups, with data separated from styling and interaction behavior. Do not ship fuzzy compressed borders, stretched art, unclickable decorative controls, inconsistent shadows, poor spacing, overly complex textures, low-contrast text, copied competitor assets, or unfinished placeholder states. If a result looks too plain, improve the layers, silhouette, highlights, and spacing before adding more noise; if it looks too cluttered, reduce decoration and strengthen hierarchy. **Final acceptance test:** the UI should communicate 'high-quality cartoony Roblox game' immediately, possess visible depth through its signature layered stroke recipe, retain functional and editable components, remain consistent across screens, and feel purpose-built rather than AI-generated by default. Deliver the final hierarchy, asset requirements, design tokens, reusable UI components, interaction behaviors, and brief testing checklist so another AI agent can maintain and extend the design reliably.
