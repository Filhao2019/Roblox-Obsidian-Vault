# Animation Poses and Timing Visual Study

An offline study board using selected examples from Roblox Creator Documentation. These are teaching examples, not screenshots of the games profiled in this vault.

> [!tip] Study actively
> Play each clip at normal speed, pause to compare frames, and write one decision for your own project. The prompts below are exercises, not measured performance claims.

## Create An Animation

Compare contact poses, weight transfer and interpolation. Scrub the clip frame by frame, sketch four key poses and test an original cycle from front and side.
