# Genre Playbooks

Short playbooks for each genre present in [[Top Games Chart 2026-11-02]]. Each gives the loop, what to copy, the retention engine, monetization, risks and the chart exemplars. Deep dives: [[Core Gameplay Loops]], [[Steal and Collect Tycoon Formula]], [[Retention and Progression Systems]], [[Monetization Patterns]]. Genre tags are from Roblox's chart; the Wikipedia list of Roblox games gives representative loops by genre ([List of Roblox games](https://en.wikipedia.org/wiki/List_of_Roblox_games)).

## 1. Steal / collect tycoon
- **Exemplars:** [[Steal An Egg]], [[Break and Steal an Egg]], [[Throw Food For Animals]], [[Steal a Brainrot]].
- **Loop:** buy/hatch random units -> passive income -> upgrade -> defend/steal -> rebirth.
- **Copy:** instant comprehension, visible income numbers, shield-and-steal tension, weekly drops.
- **Retention:** offline earnings, rebirth, rarity index, events.
- **Monetization:** luck, auto-collect, x2 cash, extra slots, limited units.
- **Risks:** rapid decay after meme peak (one tracker: -99% from peak for Steal a Brainrot), cheats, IP, similarity penalty ([RoWatcher](https://rowatcher.com/news/is-the-brainrot-trend-dying-what-ccu-data-from-three-top-games-reveals), [Discovery](https://create.roblox.com/docs/discovery)).

## 2. Garden / idle simulator
- **Exemplar:** [[Grow a Garden]].
- **Loop:** plant -> wait -> harvest -> sell -> buy rarer seeds; shared shop restock every five minutes ([Fortune](https://fortune.com/2025/07/30/roblox-video-game-grow-a-garden-viral-summer-hit/)).
- **Copy:** calm tone, global timers, gifting, mutation chase.
- **Retention:** appointments (restock), weather events, collections.
- **Monetization:** speed, auto-harvest, stock refresh, premium seeds (disclose odds if random).
- **Risks:** low skill ceiling -> fast burnout; needs events.

## 3. Incremental / RNG simulator
- **Exemplars:** [[Pet Simulator 99]], [[Sols RNG]], [[Fish It]], [[Fisch]].
- **Loop:** roll/cast/hatch -> rarity -> multiplier -> better rolls.
- **Copy:** huge rarity ladder, auras/visual flex, leaderboards, trading.
- **Retention:** index completion, time-gated worlds, events.
- **Monetization:** luck passes (about 300 Robux pattern, unverified), auto-roll, inventory ([RoWatcher](https://rowatcher.com/news/roblox-monetization-strategies-that-actually-work-in-2026)).
- **Risks:** paid random item rules ([Paid random items](https://create.roblox.com/docs/production/monetization/paid-random-items)).

## 4. Pet care / collection social
- **Exemplar:** [[Adopt Me]].
- **Loop:** care tasks -> bucks -> home/pets -> trade -> combine to Neon/Mega Neon.
- **Copy:** incremental feature rollout, hype teasers, streamer-friendly roleplay ([Naavik](https://naavik.co/deep-dives/roblox-blox-fruits-brookhaven-adopt-me/)).
- **Retention:** trading economy, seasonal pets.
- **Monetization:** many ~150 Robux passes, rotating gumball machine, modal for large items ([Contextual purchases](https://create.roblox.com/docs/en-us/production/game-design/contextual-purchases.md)).
- **Risks:** aging player base, scam trading.

## 5. Roleplay / life sim / hangout
- **Exemplars:** [[Brookhaven RP]], [[Dress To Impress]] (dress-up variant).
- **Loop:** free play, houses, vehicles, outfits; DTI adds timed contests.
- **Copy:** free customization, emotes, roleplay props.
- **Retention:** self-expression, friends, UGC feel.
- **Monetization:** premium customization, land, music; low ARPDAU but huge scale (Brookhaven about $0.02 in Naavik's analysis).
- **Risks:** chat safety; "social hangout" labels may require 16+/18+ ([Content maturity](https://create.roblox.com/docs/en-us/production/promotion/content-maturity)).

## 6. Dress-up competition
- **Exemplar:** [[Dress To Impress]].
- **Loop:** theme -> 360-second outfit build -> catwalk -> star ratings -> podium ([Wikipedia](https://en.wikipedia.org/wiki/Dress_to_Impress_(video_game))).
- **Copy:** TikTok-native identity play, brand collabs, theme props as contextual purchase.
- **Risks:** heavy UGC moderation; trend dependence.

## 7. Action RPG / grind
- **Exemplar:** [[Blox Fruits]].
- **Loop:** quests -> fight -> level -> fruits/swords -> raids.
- **Copy:** depth, content volume, big updates (one update doubled CCU), crews ([Naavik](https://naavik.co/deep-dives/roblox-blox-fruits-brookhaven-adopt-me/)).
- **Monetization:** power/convenience; randomized power items (pay-to-win criticism).
- **Risks:** no FTUE; power creep.

## 8. Battlegrounds / PvP action
- **Exemplars:** [[The Strongest Battlegrounds]], [[Jujutsu Shenanigans]], [[Blade Ball]].
- **Loop:** fight -> kill/ult -> cosmetics/moves.
- **Copy:** anime-inspired moves, skill expression, clip-friendly ults.
- **Retention:** mastery, rank, new characters.
- **Monetization:** cosmetics, emotes, private servers.
- **Risks:** IP (anime), balance, exploiters.

## 9. Shooter
- **Exemplar:** [[Rivals]].
- **Loop:** queue -> duel/round -> rank -> skins/crates.
- **Copy:** tight netcode, ranked ladders, esports feel.
- **Monetization:** cosmetics, passes; avoid pay-to-win.
- **Risks:** hit-reg complaints, cheaters.

## 10. Social deduction / 1-vs-all
- **Exemplars:** [[Murder Mystery 2]], [[Violence District]], [[Forsaken]].
- **Loop:** role assigned -> round -> win -> coins/knives/skins.
- **Retention:** collectible weapons/skins, events (MM2 swings with summer events per tracker, unverified).
- **Monetization:** crates (disclose odds), VIP, trading of collectibles (check trading policy).
- **Risks:** toxic chat, smurf accounts.

## 11. Co-op survival horror / escape
- **Exemplars:** [[99 Nights in the Forest]], [[Doors]], [[Dandys World]], [[Evade]].
- **Loop:** prep -> threat -> survive -> unlock gear.
- **Copy:** reaction-friendly scares, pre-run shop, cooperative rescue, chapter/floor updates (Doors: Hotel+, Mines, modifiers) ([List of Roblox games](https://en.wikipedia.org/wiki/List_of_Roblox_games)).
- **Monetization:** consumables, revives, cosmetics, plushies/merch.
- **Risks:** Fear descriptors and maturity labels ([Content maturity](https://create.roblox.com/docs/en-us/production/promotion/content-maturity)); young audience considerations.

## 12. Tower defense
- **Exemplars:** [[Tower Defense Simulator]], [[Anime Adventures]].
- **Loop:** waves -> place/upgrade -> earn -> unlock units.
- **Retention:** units gacha, modes, events.
- **Monetization:** summon currency, limited units (odds disclosure).
- **Risks:** grindy economy; anime IP.

## 13. Runner / obby
- **Exemplar:** [[Dont Splash]].
- **Loop:** attempt -> fail -> retry -> checkpoint -> cosmetics.
- **Copy:** instant retry, bite-size sessions, social leaderboards.
- **Risks:** short sessions hurt retention (GameAnalytics: short-session games struggle; D1 median about 4% for 0–3 minute games ([GameAnalytics 2025](https://www.gameanalytics.com/reports/2025-roblox-report))); add meta-progression.

## Choosing a genre

| If you have | Choose |
|---|---|
| 1 dev, 2 months, scripting-heavy | Steal/collect tycoon or idle simulator |
| Artist-heavy team | Dress-up, pet collecting |
| Strong netcode skills | Shooter, battlegrounds |
| Horror/art direction | Co-op survival |
| Live-ops capacity | Anything with weekly drops |

Remember Roblox's guidance: reuse familiar genre and UI patterns but offer a distinct twist ([Design for Roblox](https://create.roblox.com/docs/en-us/production/game-design/design-for-roblox.md), [Standout Games](https://create.roblox.com/docs/creator-programs/standout-games)).
