# Branding and Thumbnail Brief

A reusable brief for an original game icon or thumbnail concept. This is an original planning tool; no runnable system or tested Studio implementation is supplied by this note.

## Prepare the references

Choose references for focal composition, color separation and text hierarchy. Record which parts convey the playable premise and which merely decorate it. Use game-owned characters, original logos and art with known reuse permissions.

Example task: a mysterious hotel entrance with a readable guest silhouette and a clear central door. Create original signage and art rather than adapting another game's logo.

## Ask for a concrete deliverable

A written visual direction and a few distinct concepts, with the intended crop, focal subject, title placement and asset sources. Confirm current Roblox publishing requirements from official documentation before choosing final export dimensions.


## Acceptance review

Compare at the intended small display size, test crops and text legibility, and check that the image reflects actual gameplay. Treat discoverability or conversion improvements as hypotheses until measured in a real experiment.
