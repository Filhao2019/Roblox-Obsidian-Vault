# Reference Workflows MOC

Turn selected visual references into original Roblox implementation briefs. These notes add a working process alongside the vault's existing research and offline media. The organizational inspiration is credited to [[Roblox AI External Library]]; the briefs are original additions to this vault.

## Start here

1. Browse [[Visual References MOC]] for offline examples or [[Roblox AI External Library]] for external collections.
2. Follow [[Reference Driven Roblox Workflow]] and fill [[Reference Selection Sheet]].
3. Choose a brief below, supply the actual project constraints and request an implementation.

| Brief | Outcome |
|---|---|
| [[Style and Environment Brief]] | Cohesive shapes, materials, lighting and navigable space |
| [[UI Build Brief]] | A usable screen with responsive layout and explicit states |
| [[Animation and Cutscene Brief]] | Motion, framing and interruption behavior |
| [[VFX and Audio Brief]] | A synchronized cue with lifecycle and mix checks |
| [[Branding and Thumbnail Brief]] | Original composition and a measurable visual hypothesis |

## Plugin status

The reviewed izzyfrm repository is a media collection, not an installable plugin package. This vault update adds notes, prompts and a source registry. It does not install software, provide a Studio bridge, or turn folder links into automatically viewed images. Use it with an AI tool's existing file/image access and your project's chosen Studio workflow.
